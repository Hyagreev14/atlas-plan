# Architecture decision records

Use one numbered ADR per consequential technical decision. Each record should include status, context, decision, alternatives, consequences, date and conditions for revisiting.

## Current records

- [ADR-0001: Electron desktop stack](0001-electron-stack.md)

## Status values

Proposed, Accepted, Superseded or Rejected. A decision is not final merely because it appears in a discussion; mark it Accepted only when the project owner has chosen it.
