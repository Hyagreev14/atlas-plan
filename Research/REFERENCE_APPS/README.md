# Reference application reviews

Evaluate reference applications by the problem they solve, not visual similarity alone.

## Review dimensions
- First-run experience and onboarding.
- Information architecture and navigation.
- Project/workspace handling.
- Tool discovery and launch.
- AI interaction and permission presentation.
- Search, keyboard shortcuts and command access.
- Settings and customisation.
- Accessibility and display scaling.
- Performance, with measurement method and platform.
- Distribution, signing, updates and trust.
- Strengths, friction and patterns worth adapting.
