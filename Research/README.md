# Research documentation

This directory records evidence and observations from reference applications, developer workflows and user research. Research should inform ATLAS without turning into a copy of another product.

## Documents

- [Research log](RESEARCH_LOG.md)
- [Reference application reviews](REFERENCE_APPS/README.md)
- [DevAtlas review template](REFERENCE_APPS/DEVATLAS.md)

## Research rules

- Separate direct observation from interpretation and proposed ATLAS requirements.
- Record app version, platform and date when known.
- Do not infer hidden implementation details from appearance.
- Do not bypass operating-system security warnings to inspect an unsigned application.
- Prefer official documentation, release notes and safe screenshots when an app cannot be run.
- A reference pattern is inspiration, not a requirement to reproduce it.
