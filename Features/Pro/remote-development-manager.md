# Remote Development Manager

**Release:** ATLAS Pro  
**Status:** Planned

## Purpose
Manage supported remote development environments such as SSH hosts, WSL distributions, remote Linux machines and development VPS instances.

## Boundaries
Remote file and command operations use the same AAP, permission and audit boundaries as local operations.
