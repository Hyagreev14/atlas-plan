# Visual Workflow Builder

**Release:** ATLAS Pro  
**Status:** Planned

## Purpose
Build workflows visually from triggers, actions, conditions, delays and approval checkpoints.

## Boundaries
Workflows remain inspectable and cancellable; every action retains its own permission requirements.
