# Visual Context Mode

**Release:** ATLAS Pro  
**Status:** Planned

## Purpose
Optionally provide screenshots or selected-window images as context for voice requests, enabling screen-aware assistance.

## Boundaries
OFF by default. Requires a vision-capable model and resource/privacy warning. Screenshots are context, never authorization; cloud sharing is disclosed.
