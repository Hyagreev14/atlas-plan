# Extension Ecosystem

**Release:** ATLAS Pro  
**Status:** Planned

## Purpose
Extend ATLAS with integrations, panels, tools and workflow actions through a declared capability model.

## Boundaries
Extensions receive only explicitly granted access; filesystem, Vault and command capabilities are restricted by default.
