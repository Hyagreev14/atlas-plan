# AAP and Safe Execution

**Release:** ATLAS Core  
**Status:** Planned

## Purpose
Provide a structured protocol through which AI can request supported ATLAS actions.

## Boundaries
AI requests; ATLAS validates, authorises and executes. AI cannot set approval requirements or approve itself.
