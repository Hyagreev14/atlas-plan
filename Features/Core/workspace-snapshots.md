# Workspace Snapshots

**Release:** ATLAS Core  
**Status:** Planned

## Purpose
Save and restore workspace configurations such as selected projects, launch profiles and layout.

## Boundaries
Store references rather than project contents or secrets; preview unavailable items before restore.
