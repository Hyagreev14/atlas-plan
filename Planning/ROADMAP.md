# ATLAS roadmap

**Planning date:** 24 November 2026

## Phase 1 — Research and specification (24 Nov 2026–Jan 2027)
- Evaluate reference apps safely.
- Finalise Core journeys and scope.
- Complete Figma foundations, components, screens and prototypes.
- Define Electron architecture, IPC, AAP and permission design.
- Resolve major storage, provider and platform questions.
- Prepare development conventions.

**Exit:** Core scope is understandable; major architecture decisions are recorded; primary Figma flows are reviewed.

## Phase 2 — Core implementation (February 2027)
- Begin React + TypeScript + Electron implementation.
- Use approved Figma handoff.
- Build app shell and foundational services first.
- Implement vertical slices, not disconnected screens.
- Ask Hack Club Slack about student signing/distribution experiences.
- Investigate SignPath and alternatives without assuming eligibility.

**Exit:** working application skeleton and tested foundational workflows; release blockers visible.

## Phase 3 — Core validation/release (target: mid-March 2027)
- Complete agreed Core scope or transparently defer unfinished items.
- Test Windows and Linux builds, installation, launch, update and uninstall.
- Validate permissions and secret handling.
- Publish checksums, source revision, notes and known issues.
- Disclose Windows signing status.

## Phase 4 — Pro development (target start: late March 2027)
Prioritise Pro from Core feedback, preserve Core stability, and test compatibility/migrations.

## Caveats
School commitments and available time may affect targets. Update this roadmap honestly rather than silently lowering quality.
