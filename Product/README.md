## Product definition

ATLAS is a daily starting point and development command centre. It helps a developer orient themselves, open projects and tools, inspect useful context and work with an AI assistant under user-controlled permissions. It complements existing specialist tools rather than trying to replace every IDE, terminal, Git client or monitoring application.

## Scope discipline

Every Core capability must support a clear user need, have an understandable workflow and be testable. Core must be useful independently. Pro adds depth after Core; it must not hold essential everyday functionality hostage.
